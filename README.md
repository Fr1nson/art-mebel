# 🪑 Art-Mebel

> Веб-приложение для мебельного магазина — каталог, корзина, админ-панель

---

## 📋 Описание

**Art-Mebel** — это современное веб-приложение для мебельного магазина.  
Проект включает публичную часть с каталогом товаров и личным кабинетом, а также административную панель для управления ассортиментом и заказами.

---

## ✨ Возможности

### 🛍️ Публичная часть
- [x] Каталог мебели с фильтрами и поиском
- [x] Карточки товаров с фото и описанием
- [x] Корзина и оформление заказа
- [x] Адаптивная вёрстка (mobile-first)
- [x] Форма обратной связи

### ⚙️ Административная панель
- [x] Управление товарами (CRUD)
- [x] Управление категориями
- [x] Просмотр и обработка заказов
- [x] Загрузка и управление изображениями
